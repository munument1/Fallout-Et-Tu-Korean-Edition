## 보류·추가 점검
- 데커/케인/그린 보안관 적대 분기, 두 청부살인 의뢰의 결제 보상, 동적 이름 조합, 화제 응답 UI를 게임 내 확인할 것.
- 120의 scripts/caps 동일화는 실제 게임에서 500캡 지급 시 확인 필요.
- 차기 NPC는 남은 원문·SSL 대응 가능 캐릭터 중 선택. 전체 정밀 검수 및 실게임 테스트는 미완료.

## 자동 검증 결과
- 원래 영어/한국어 MSG 각 216개 및 원문 SSL 407행과 분기 대조.
- 한국어 수정 120개 ID; 번호/음성 라벨 전부 유지, CP949 엄격 변환. 수정 전후 물음표 개수 36→37로 손상성 일괄 치환 발생하지 않음.
- manifest에서 DECKER.msg 항목만 갱신하고 SHA256/바이트 크기 일치를 별도 확인함.
- python korean/build_overlay.py: 성공, 원본 1691개 수록.
- PYTHONUTF8=1 환경에서 python -m unittest discover -s korean/tests -v: 총 12개 모두 통과.
- 실게임 출력 테스트는 아직 미실시. 공개 릴리스·기준 브랜치 병합 미진행.
